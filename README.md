# Landing Page TK Bhakti Pertiwi Cimalaka

Landing page sederhana untuk memperkenalkan sekolah, menampilkan program, fasilitas, testimoni, dan formulir pendaftaran.

## Jalankan secara lokal

1. Install dependensi:
   ```bash
   npm install
   ```
2. Jalankan aplikasi:
   ```bash
   npm run dev
   ```
3. Buka alamat yang ditampilkan di browser, biasanya:
   ```text
   http://localhost:3000
   ```

## Build untuk produksi

```bash
npm run build
```

## Catatan

- Aplikasi sudah dikonfigurasi agar bisa diakses dari localhost dan preview.
- Form pendaftaran saat ini memvalidasi input di sisi klien dan menampilkan pesan sukses.
